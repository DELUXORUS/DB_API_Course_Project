Курсовая работа по созданию информационной системы для интернет-провайдера.
Использованные технологии:
* Flask
* REDIS (кэширование)
* MySQL

Программная архитектура:
* Монолит (Для внутренних пользователей: авторизация, работа с запросами, работа с отчётами, работа с подключением услуг)
* Микросервис для авторизации внешних клиентов
